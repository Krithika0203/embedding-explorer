# 🧠 Embedding Explorer

A simple AI application built using **Python and Streamlit** that demonstrates how text embeddings work and how **semantic similarity search** can be performed.

## 🌐 Live App

🚀 **Try the app here:**
https://embedding-explorer-34ehwsucdjcjaa84xfbyjf.streamlit.app/

---

## 🚀 Features

✨ Generate text embeddings
📚 Store multiple text embeddings
🔎 Perform semantic similarity search
📊 View stored data and embedding statistics

---

## 🛠 Tech Stack

* Python
* Streamlit
* NumPy
* Pandas

---

## 📸 Example

Add text entries and search for similar ones using embeddings.

Example:

Text 1: AI is transforming healthcare
Text 2: Machine learning helps prediction

Search Query: AI in medicine

Result → The app finds the most similar stored text using embedding similarity.
