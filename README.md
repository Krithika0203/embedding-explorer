# 🧠 Embedding Explorer

A simple AI application built using **Python and Streamlit** that demonstrates how text embeddings work and how semantic similarity search can be performed.

## 🚀 Features

✨ Generate text embeddings  
📚 Store multiple text embeddings  
🔎 Perform semantic similarity search  
📊 View stored data and embedding statistics  

## 🛠 Tech Stack

- Python
- Streamlit
- NumPy
- Pandas
